# 모델 세대가 바뀌면 하네스의 가정을 하나씩 다시 잰다

## 상황
모델이 한 세대 올랐을 때, 하네스가 무거워졌다고 느낄 때, 하네스 요소가 왜 있는지 기억나지 않을 때.

## 교훈
- 하네스 요소는 저마다 "모델이 이것을 못 한다"는 가정이다. 가정은 낡는다. 요소를 하나씩 빼고 같은 요청을 두 팔에서 돌려 본다.
- 지시문("요청 → 스킬" 표)은 먼저 뺀다. 그 프로젝트에만 있는 사실(인덱스가 있는지, 명령 경로)은 남긴다.
- 스킬이 안 불리는 요청 꼴이 나오면 세션 안내에 줄을 더하지 않는다. 스킬 설명에 그 꼴을 한 구절 넣는다.
- 경고 훅은 경고 뒤에 모델이 무엇을 했는지로 잰다. 그대로 이어 갔으면 그 경고는 잡음이다.
- 늘 들어가는 규칙 가운데 특정 파일을 다룰 때만 필요한 것은 경로 조건부 규칙(`~/.claude/rules/*.md` 의 `paths`)으로 옮긴다.
