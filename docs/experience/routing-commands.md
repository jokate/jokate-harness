# 스킬 이름만 알려 주면 모델은 grep 으로 간다

## 상황
세션 시작 안내 · 규칙 파일에 "구조 질문 → game-onboard" 처럼 스킬 이름만 있고, 인덱스는 그 스킬 본문에서만 소개될 때.

## 교훈
스킬을 거치지 않아도 바로 쓸 수 있게, 있는 인덱스만 골라 **명령 줄 그대로**(경로 포함) 준다. 무엇을 grep 으로 찾지
말아야 하는지(클래스 · 함수 · 구조체 이름)를 행동 단위로 적는다. "인덱스를 먼저 쓴다" 같은 일반론은 행동을 바꾸지 않는다.
