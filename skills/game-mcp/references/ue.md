# Unreal Engine MCP

## 목차
1. 선택지
2. 알려진 함정 유형
3. 애셋 유형별 조회 → 수정 → 검증 순서

## 1. 선택지

| 종류 | 설명 | 상태 |
|---|---|---|
| Epic 공식 "Unreal MCP" | UE 5.8 실험 기능. 에디터 프로세스 안에서 loopback HTTP 서버, 인증 없음. 커스텀 도구는 Toolset 정의로 추가 | 커뮤니티·문서 경유 정보, **검증 안 됨** |
| 커뮤니티 구현 | C++ 플러그인 + 외부 서버(Python/TS) 구조가 흔함 (chongdashu/unreal-mcp, ChiR24/Unreal_mcp 등) | 프로젝트별 |
| 사내·자체 구현 | 도구 이름·인자 규칙이 프로젝트마다 다르다 | 해당 프로젝트 문서 |

도구가 수백 개면 Claude Code 의 tool search 가 이름만 상주시키고 스키마는 호출 때 불러온다. 도구를 못 찾으면 ToolSearch 로 키워드 검색.

## 2. 알려진 함정 유형

구체 사례는 프로젝트마다 다르다. 유형으로 기억하고, 사례는 그 프로젝트의 `mcp_guards.json` 에 쌓는다.

| 유형 | 증상 | 대응 |
|---|---|---|
| 후처리 미발화 | 속성은 들어갔는데 에디터가 PostEditChangeProperty 로 만들던 파생 데이터가 없다 | 에디터 Python 에서 `set_editor_property` 로 다시 넣거나, 애셋을 열어 재저장 |
| 복제로 깨짐 | 복제한 애셋의 길이·참조가 0 이 되거나 원본을 가리킨다 | 복제 대신 새로 생성 후 속성 이식. 복제했다면 핵심 값 재조회 |
| 배열·구조체 통째 쓰기 실패 | export 텍스트 한 번에 넣으면 파싱 실패 | 원소 단위 `Name[i] = (...)` |
| 인자 생략 | 선택 인자처럼 보이지만 빠지면 실패 | 스키마의 모든 인자를 명시 |
| Python 스코프 | `execute_python` 이 분리 스코프라 최상위 함수를 내부에서 못 찾음 | 평문 루프, 또는 정의 직후 `globals().update` |
| 세션 끊김 | 토큰·세션 오류가 연속 | 에디터 재시작이 필요할 수 있다 — 사용자에게 요청 |

## 3. 조회 → 수정 → 검증 순서

| 애셋 | 조회 | 검증 |
|---|---|---|
| Blueprint | 그래프·변수·CDO 조회 도구 | 컴파일 도구 → 컴파일 결과 확인 |
| 머티리얼 | 노드·연결 조회 | 재컴파일 + 에러 조회 |
| 애니메이션 몽타주 | 섹션·세그먼트·노티파이 조회 | 길이·섹션 재조회 |
| StateTree / BT | 상태·태스크·전이 조회 | 컴파일·검증 도구 |
| DataAsset / DataTable | 속성·행 조회 | 같은 속성 재조회 |
| 레벨 액터 | 액터 목록·속성 | 속성 재조회, 필요 시 스크린샷 |

도구 이름은 MCP 구현마다 다르다. 이 표는 "무엇을 조회해야 하나"의 체크리스트로만 쓴다.
