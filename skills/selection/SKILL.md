# selection — 고를 것을 양식으로 받는다

사용자가 A안 · B안 · C안 중에서 고를 때 쓴다.
대화에 이미 나온 선택지를 양식으로 옮긴다. 선택지가 아직 없으면 먼저 만든다(게임 프로젝트의 구조 선택이면 `game-architecture` 로).

## 순서

1. 양식 JSON 을 쓴다. 꼴은 [references/form-sample.json](references/form-sample.json) 그대로다.
   - 위치: `<프로젝트>/Saved/ClaudeArch/decide/<YYYYMMDD>-<주제>.json`
   - Unity 는 `Library/ClaudeArch/decide/`.
   - 그 밖의 프로젝트는 파일을 쓰지 않는다. 2번의 명령에서 `<양식.json>` 자리에 `-` 를 쓰고 JSON 을 표준 입력으로 준다(`.claude/` 아래에 쓰면 권한을 묻는다).
2. 양식을 띄운다. **백그라운드로 돌린다.**
   `python ~/.claude/skills/selection/scripts/decide.py form <양식.json> --project <프로젝트 루트>`
   - 출력에 `점검:` 줄이 있으면 양식을 고쳐 다시 돌린다. `양식 오류` 면 뜨지 않는다.
   - 띄웠으면 대화에는 한 줄만 쓴다: 무엇을 묻는 양식인지, Enter 로 보내면 된다는 것.
   - 백그라운드를 쓸 수 없으면 제한 시간을 10분으로 두고 그냥 돌린다. 그 안에 안 보냈으면 같은 명령을 다시 돌린다(답은 저장돼 있다).
3. 사용자가 Enter 로 보내면 명령이 끝난다. 명령이 끝났다는 알림이 오면 그 출력을 읽는다. 답이 거기 있다.
   - Enter 는 지금 고른 대로 보낸다. 안 고른 질문은 미결로 온다. 한 번에 다 받아들이는 버튼은 없다.
   - 안마다 '기각' 을 누르고 이유를 적을 수 있다. 이유가 비면 보내지지 않는다. 질문마다 피드백 칸이 있다.
   - 탭은 스스로 닫힌다. 양식 파일은 지워진다. HTML 파일은 처음부터 남지 않는다.
   - 사용자가 '이 결정을 장부에 남긴다' 를 표시한 결정만 명령이 결정 장부(`<프로젝트>/.claude/decisions.jsonl`)에 적는다.
   - 표시하지 않은 결정은 장부에 없다. 내가 대신 적지 않는다. 남길 만해 보여도 한 줄로 권하기만 한다.
4. 답을 읽고 바로 이어 간다.
   - 고른 안으로 진행한다. 다시 묻지 않는다.
   - 피드백은 지시다. 그대로 하고 바꾼 것을 한 줄로 알린다.
   - `기각한 안` 은 다시 내지 않는다. 이유를 읽고, 같은 이유에 걸리는 다른 안이 있으면 그것도 고친다.
   - 고른 안 없이 기각만 온 질문은 '다시 내라' 는 뜻이다. 이유와 피드백을 반영해 선택지를 고치고 그 질문만 새 양식으로 낸다.
     새 양식의 그 질문에 `dropped_before` 로 앞서 기각된 안과 이유를 적는다(`["Hit — 엔진 이름과 겹친다"]`). 고르면 장부의 버린 안에 같이 남는다.
   - `추천과 다름` 이어도 고른 것을 따른다. 내 반대는 한 줄로만 남긴다.
   - `체크하지 않은 것` 은 사용자가 확인하지 않은 조건이다. 내가 확인할 수 있으면 진행 전에 확인하고 결과를 알린다.
   - `안 고름` 인 질문은 미결이다. 그 답에 달린 일은 하지 않는다.
   - 끝 코드 2(보내지 않고 닫음) · 3(시간 초과)이면 고른 것이 없다. 진행하지 않고 한 줄로 알린다.

## 양식 쓰는 법

- 질문은 5개 이하다. 답에 따라 바뀌는 것(`changes`)이 없으면 묻지 않는다.
- 다른 질문의 답에 달린 질문은 이번 양식에 넣지 않는다. 답을 받은 뒤 다음 양식으로 낸다.
- 선택지는 2~4개다. 가장 작은 변경(국소 패치)을 기준선으로 넣는다.
- 추천은 질문마다 하나다. `why` 네 칸(문제 · 버린 안 · 대가 · 뒤집는 조건)을 채운다.
- 선택지 칸은 한 구절씩 쓴다.
  - `summary` 무엇을 하나 · `next` 다음 같은 요청 때 고칠 곳 · `gain` 얻는 것 · `loss` 잃는 것
- `checks` 는 사용자가 고르기 전에 스스로 확인할 조건이다. 7개 이하.
  - 내가 코드로 확인할 수 있는 사실은 넣지 않는다. 확인해서 선택지 칸에 적는다.
- `asks` 는 사용자만 아는 것을 묻는 칸이다. 한 줄로 답할 수 있게 묻는다.
- `dropped_before` 는 앞 양식에서 기각된 안이다. 다시 내는 질문에만 쓴다.
- 한 줄에 사실 하나, 120자 이하. 파일:줄 · 커밋 번호는 넣지 않는다.
- `id` 는 영문 · 숫자 · `-` · `_` 만 쓴다.

## 서버를 못 띄울 때

브라우저가 다른 기기에 있거나 로컬 포트를 못 열면 `--static` 을 붙인다. HTML 파일이 양식 옆에 생긴다.
1. 사용자가 Enter 를 누르면 답이 복사된다. 사용자가 그것을 대화에 붙인다.
2. 붙여 준 JSON 을 `<양식 이름>.answers.json` 으로 양식 옆에 저장한다.
3. `python ~/.claude/skills/selection/scripts/decide.py done <양식.json> --project <프로젝트 루트>`
   요약을 찍고, 장부에 적고, 양식 · 답 · HTML 파일을 지운다.

## 하지 말 것

- 양식을 띄운 뒤 같은 질문을 대화로 또 묻기.
- 보내기 전에 고른 것으로 치고 진행하기.
- 장부 파일을 직접 고치기. `decide.py` 로만 적는다.
- 장부를 커밋하기. 사용자가 시킬 때만 올린다.
