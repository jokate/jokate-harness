# 그림 형식 고르기 — "무엇이 바뀌나" 로 고른다

"구조를 보여 줘" 가 곧 아키텍처 그림은 아니다. 이번 변경에서 **실제로 바뀌는 것** 하나를 먼저 한 줄로 정하고,
그것이 가장 잘 보이는 diagram-design 형식을 고른다. 사용자 피드백(2026-10-20): "무조건 아키텍처로 뽑는다 —
원하는 형식에 따라 다르게, 기존 형식에서 어떻게 바뀌는지에 맞는 다이어그램을 골라야 한다".

## 바뀌는 것 → 형식

| 이번에 바뀌는 것 | 게임 코드 예 | diagram-design 형식 | 파일 표기 | 전후 보이는 법 |
|---|---|---|---|---|
| 런타임 객체 · 모듈 사이 연결 (누가 누구를 갖고 부르나) | 퀘스트 매니저를 서브시스템으로, 판정 위치를 다른 객체로 | Architecture delta | `architecture-delta` | 한 장 (Before · 바뀌는 것 · After) |
| 클래스 정의 — 상속 계층 · 책임 · 멤버 | 파생 12개 오버라이드 → 컴포넌트 조합, 인터페이스 도입 | UML class | `uml-class` | 전 · 후 두 장 |
| 상태와 전이 | 어빌리티 단계, AI · 보스 페이즈, UI 화면 흐름 | State machine | `state-machine` | 전 · 후 두 장, 바뀐 전이 강조 |
| 호출 · 이벤트 순서와 타이밍 | 델리게이트 순서, 초기화 순서, RPC · 복제, 입력 → 판정 | Sequence | `sequence` | 전 · 후 두 장 |
| 조건 분기 · 판정 로직 | 히트 가능 판정, 표시 조건, 데미지 계산 분기 | Flowchart | `flowchart` | 전 · 후 두 장, 바뀐 분기 강조 |
| 데이터 구조 | DataTable · DataAsset 필드, 세이브 포맷, 테이블 관계 | ER / data model (DB 면 Database schema) | `er` · `db-schema` | 전 · 후 두 장 |
| 데이터가 흘러가는 길 | 입력 → 처리 → 출력, 애셋 쿠킹, 인덱스 빌드, 로그 수집 | Data flow | `data-flow` | 전 · 후 두 장 |
| 모듈 의존 · 순환 | Build.cs · asmdef 의존, 순환 끊기 | Dependency graph | `dependency` | 전 · 후 두 장, 끊긴 간선 점선 |
| 계층 · 경계 규칙 | 엔진 ↔ 게임 ↔ 콘텐츠, 서버 ↔ 클라 경계 | Layer stack | `layers` | 전 · 후 두 장 |
| 포함 · 소유 범위 | 어떤 액터가 어떤 컴포넌트 · 슬롯을 갖나 | Nested | `nested` | 전 · 후 두 장 |
| 직군 사이 인계 | 기획 → 프로그램 → 아트 데이터 인계 | Swimlane | `swimlane` | 전 · 후 두 장 |
| 단계적 이관 · 순서 | 데이터 이관, 리팩터링 순서, 호환 기간 | Timeline (일정이면 Gantt) | `timeline` · `gantt` | 한 장 (단계 자체가 전 → 후) |

"컴포넌트로 바꾼다" 는 두 가지다: **클래스 정의**가 바뀌는 것(상속 → 조합)이 핵심이면 UML class,
**런타임에 누가 누구를 갖고 부르는지**가 핵심이면 Architecture delta. 헷갈리면 둘 다(한 문서에 두 형식까지).

선택지 비교 자체를 한 장으로 보이고 싶으면 **Quadrant**(`quadrant`)(가로: 지금 작업량 · 위험, 세로: 다음 요청 때 고칠 곳)를 더한다.
신호(hotspot · co-change)는 표로 충분하다 — 그림이 필요하면 Bar chart · Heatmap.

## 규칙

- **핵심 하나**: 그림 절 첫 줄에 `바뀌는 것: <한 줄> → <형식>` 을 적는다. 형식은 한 문서에 두 가지까지(예: 연결 + 순서).
- **사용자가 형식을 말하면 그것을 쓴다** ("시퀀스로", "상태도로", "ER 로").
- **전 · 후 두 장**인 형식은 같은 배치 · 같은 이름을 지키고, 바뀐 요소만 강조색(accent, 2개 이하) · 사라진 요소는 점선으로 둔다.
  두 장을 서로 다르게 배치하면 바뀌지 않은 것도 바뀐 것처럼 보인다.
- **파일 이름**: `<문서 이름>-구조-<선택지>-<파일 표기>.html`, 두 장이면 끝에 `-전` · `-후`
  (예: `20261020-조건-구조-C-sequence-전.html`, `…-후.html`). render.py 가 이름순(전 → 후)으로 '그림' 절에 끼워 넣는다.
- 형식마다 diagram-design 의 type 문서(`type-<형식>.md`)를 먼저 읽고 그 예산(노드 · 간선 · 줄 수)을 지킨다.
- 선택지 A(국소 패치)처럼 거의 안 바뀌는 선택지는 "그림 없음 — 표의 '고칠 곳' 으로 충분" 이라고 적고 건너뛰어도 된다.
